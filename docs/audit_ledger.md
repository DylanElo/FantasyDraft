### 🔴 Critical — correctness bugs

- [x] **Missing winner detection on simultaneous double-KO.** **Fixed 2026-08-01:** `resolver.py:check_winner` now declares an explicit draw (`winner_id=None`, `phase=FINISHED`, a `battle_finished` event) when `len(alive_players) == 0`, instead of leaving `phase=PLANNING` for up to 12 turns. - [x] **Race condition, confirmed.** **Fixed 2026-08-01:** `on_battle_v2_leave_pvp` (`web/app.py`) now calls `remove_v2_pvp_lobby_player` inside the same `with lifecycle_lock:` block as `acknowledge_finished_match`, instead of after it unlocks.
